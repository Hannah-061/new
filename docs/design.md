# 畫面設計說明

> 給下一步做前端時使用。畫面內容與行為以 `docs/architecture.md` 第 7 節為準，這份文件記錄「長什麼樣子」。
> 設計稿（可在畫布上看）：https://claude.ai/artifact/BJoioVzY62CoDRWNurhUYK
> 這個連結目前只有你自己能開。設計稿是靜態畫面，不能點，數字和文字都是示意內容。
> 本文件對應設計稿最後更新的版本（2026-10-13，已含淺橘色調整）。之後設計稿再改，請同步更新這裡。

## 1. 風格

**匿名聊天室**：淺色、乾淨、手機優先。暖白底，深灰文字。兩個重點色：**深青綠**用在功能性的地方（送出按鈕、連結、焦點框、「你」標記），**淺橘**用在入口頁的進入按鈕和自己的訊息泡泡。入口頁與空狀態用一個小面具圖示，代表匿名。

最初曾定過「深夜電台」暗色風格，後來改成淺色，現在以這份為準。

## 5. 版面與元件規格

**共通**
- 可點擊的東西最小 44×44px。
- 圓角：輸入框與按鈕 12px；人數按鈕與提示膠囊為全圓角；訊息泡泡 16px，靠發話者的那一角收成 4px。
- 圖示一律是描邊式的簡單線條圖示（內嵌 SVG），不使用表情符號。

### 5.1 入口頁
由上到下：面具圖示（56px 方塊）→ 標題「匿名聊天室」→ 一句說明 →（空白）→ 表單 → 隱私提醒 → 示範模式提示。
- 表單：標籤「你的代號」、輸入框（高 56px，預填上次的代號）、格式說明、錯誤區、「進入聊天室」按鈕（高 56px，淺橘底 `#FFC48A`、深色字、右側箭頭）。
- 輸入框聚焦時邊框為主色；有錯誤時邊框為錯誤紅。
- 錯誤區有紅色圖示加文字，預留至少 22px 高度，避免出現時畫面跳動。
- 隱私提醒：「這裡的訊息所有人都看得到，請不要分享私密資訊。」
- 示範模式提示（只有階段一）：虛線外框的小膠囊，「示範模式：訊息只存在你的瀏覽器」。階段二要移除。

### 5.2 聊天室（手機）
- **頂端列**（高 64px，下方有分隔線）：左邊房間名稱；右邊「N 人在線」按鈕（圓角膠囊，含綠色圓點和箭頭）與「離開」圖示按鈕。
- **訊息區**：內縮 16px，訊息由下往上堆疊，間距 14px。
  - 他人：代號（有顏色）在泡泡上方；白底泡泡，右邊接時間；最大寬度約 90%。
  - 自己：靠右，淺橘泡泡 `#FFC48A`、深色字，左邊接時間；不顯示代號；最大寬度約 78%。
  - 進出提示：置中的一行小字，例如「小明 加入了聊天室」。
  - 網址：主色、加底線，新分頁開啟。
  - 傳送中：時間的位置改成時鐘圖示加「傳送中」，泡泡變淡。
  - 傳送失敗：整則是一個按鈕，紅底紅框，泡泡下方一行「傳送失敗，點一下重送」附重試圖示。
- **「有新訊息 ↓」按鈕**：小型膠囊（高 32px、字 13px、圖示 14px），淺青綠底、主色外框。位置在訊息區左側、與最底部那則訊息同一高度，靠左對齊內容邊緣，不遮住任何泡泡。使用者往上捲在看舊訊息時才出現。
  - 注意：它比一般可點擊目標（44px）小，這是你指定的。實作時可以把可點擊範圍用透明邊距撐到 44px，外觀不變。
- **輸入區**（靠底，上方有分隔線）：
  - 「慢一點，等一下再送」提示在輸入框上方，主色小字，短暫出現。
  - 圓角輸入框（高 44px）加圓形送出按鈕（44px）。內容為空白時，送出按鈕為停用樣式。
  - 輸入框有隱藏的標籤「訊息內容」，給螢幕閱讀器使用。

### 5.3 展開線上名單（手機）
- 點「N 人在線」後，聊天內容上方出現遮罩，並從底部升起一個圓角的面板。
- 「N 人在線」按鈕此時外框變主色、底色變淺青綠、箭頭朝上。
- 面板：頂端小拉把 → 標題「目前在線 N 人」與關閉按鈕（44px）→ 名單。
- 名單每列高 48px：綠色圓點加代號，自己的代號後面有主色小標籤「你」。

### 5.4 空狀態（手機）
- 訊息區置中：較大的面具圖示（80px 方塊）→「還沒有人說話」→「你是第一個。先打個招呼吧，等等也許有人會經過。」
- 人數顯示「1 人在線」；送出按鈕為停用。

### 5.5 聊天室（電腦）
- 左右兩欄：左邊是聊天主區域（彈性寬度），右邊是固定 280px 的線上名單側欄，兩者間有細分隔線。
- 頂端列（高 72px）：房間名稱、「N 人在線」（僅顯示，不能點）、右側有文字的「離開」按鈕。
- 訊息內容欄最大寬度 760px，置中；他人泡泡最大約 70%，自己的約 60%。
- 輸入區：同樣最大寬度 760px。上方左邊是「慢一點」提示，右邊是字數提示（接近 500 字上限時才出現，設計稿的「還剩 14 字」只是示意）。輸入框兩行高（72px），右邊是有文字的「送出」按鈕。輸入框的提示文字說明 Enter 送出、Shift+Enter 換行。
- 側欄：標題「目前在線 N 人」，名單每列高 44px，自己有「你」標籤。

## 6. 設計稿「沒有畫」的東西

實作時需要補上，風格照上面的規則：

1. 按下「進入聊天室」後的**連線中**狀態（按鈕停用、顯示進行中）。
2. 入口頁的**無法連線**錯誤（架構文件 7.1 有這一項）。
3. 入口頁輸入**格式錯誤**的即時提示（太短、太長、有不允許的字元）。
4. 輸入框接近 500 字時的字數提示在手機版的樣子。
5. **英文版**介面。設計稿只有繁體中文；英文字通常較長，按鈕與提示要留餘裕。
6. 手機寬度與電腦寬度之間（平板、窄視窗）的版面：設計稿只有 390px 與 1280px 兩個點。實作時以 720px 附近作為切換點是合理的，可再依實際效果調整。
7. 空狀態只畫了手機版，電腦版比照辦理即可。
8. 滑鼠移到按鈕上、按下去的樣子。

## 7. 實作時的注意事項

- 對比與無障礙：所有按鈕用真正的 `<button>`；圖示按鈕要有 `aria-label`；輸入框要有 `<label>`；錯誤區用 `role="alert"`；「慢一點」用 `role="status"`。
- 手機輸入框字級不要小於 16px。
- 設計稿裡的訊息、代號、時間都是示範內容，不要寫死在程式裡；階段一的示範機器人可以用類似的內容。
- 視覺與文字的對應：訊息狀態有三種（傳送中、已送出、失敗），進出提示不存進歷史，這些行為見架構文件第 5、6 節。
- 設計稿的原始檔目前只在設計畫布上。要開始寫前端時，請從畫布上對照實際畫面，或告訴我，我可以把畫面的 HTML 匯出放進 repo 當參考。
